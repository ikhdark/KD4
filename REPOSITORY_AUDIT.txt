R001 [P1] FIXED / VALIDATED
Linux sandbox bwrap discovery can execute a writable/PATH-controlled candidate
before sandboxing. Evidence: codex-rs/linux-sandbox/src/launcher.rs:51-151 and
codex-rs/sandboxing/src/bwrap.rs:168-190. Fix: use the verified bundled binary or
strict trusted-system locations and preserve file identity between probe/exec.

R002 [P1] FIXED / VALIDATED
Windows sandbox ACL enforcement ignores protection failures and can report setup
success. Evidence: codex-rs/windows-sandbox-rs/src/spawn_prep.rs:267-345 and
src/bin/setup_main/win.rs:916-1044. Fix: fail closed on every enforcement-relevant
ACL error, except verified idempotent results.

R003 [P1] FIXED / VALIDATED
Workspace-mutating processes continue after lease heartbeat rejection/error.
Evidence: codex-rs/core/src/tools/command_execution.rs:166-205 and
core/src/tools/handlers/shell.rs:489-534. Fix: cancel/reap the process when lease
ownership is lost and report failure.

R004 [P1] FIXED / VALIDATED
The 64-entry running-process ledger evicts a still-live process and finalizes its
mutation lease without terminating it. Evidence:
codex-rs/core/src/tools/command_execution.rs:18-20,305-344. Fix: reject at
capacity or terminate/reap before releasing a lease.

R005 [P2] FIXED / VALIDATED
Mutation finalization marks itself final before the durable store call succeeds,
preventing retry after transient failure. Evidence:
codex-rs/core/src/tools/command_execution.rs:218-229. Fix: commit finalized state
only after successful storage, with serialized retry state.

R006 [P1] FIXED / VALIDATED
Shell and unified-exec mutation leases resolve from turn cwd instead of effective
command/environment cwd. Evidence: core/src/tools/handlers/shell.rs:192-261 and
core/src/tools/handlers/unified_exec/exec_command.rs:180-249. Fix: resolve and
lease the repository containing the actual effective cwd.

R007 [P1] FIXED / VALIDATED
Managed network-policy refresh commits tighter settings before proxy refresh, and
refresh failures leave a stale broader policy active. Evidence:
core/src/session/mod.rs:1088-1157,1512-1550 and
core/src/session/turn_context.rs:610-667. Fix: atomic/fail-closed refresh before
settings commit; disable stale proxy policy on error.

R008 [P1] FIXED / VALIDATED
Retained command-output artifacts have count limits but no byte quotas. Evidence:
core/src/tools/command_output_artifact.rs:21-27,136-162 and unified-exec streaming
callers. Fix: per-artifact/thread/global byte caps with explicit truncation.

R009 [P1] FIXED / VALIDATED
Artifact streaming drops the creation handle and reopens a command-visible path
without no-follow/identity checks, allowing link replacement when CODEX_HOME is
writable by the command. Evidence: command_output_artifact.rs:74-99,246-304 and
unified_exec/process.rs:458-476. Fix: retain the original handle or verify a
no-follow reopen against the original file identity.

R010 [P1] FIXED / VALIDATED

missing protected path without proving the sandbox created it, risking deletion
of concurrent host/IDE data. Evidence: linux_run_main.rs:542-567,1050-1148.
Fix: fail/terminate without recursive deletion unless creator/inode attribution
is established.
