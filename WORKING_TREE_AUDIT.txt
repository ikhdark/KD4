CONFIRMED / REJECTED FINDINGS
BUG-01 — Typed workspace owners can be scavenged while alive. The 120-second
actor timestamp is the only orphan signal; accepted typed source/tool/progress
boundaries do not consistently heartbeat, and begin_workspace_mutation sweeps
before a validated invoking owner can renew. Repair: validate-and-renew the exact
active binding before an invoking mutation sweep, heartbeat accepted boundaries,
and reconcile live AgentControl threads before root sweeps. Validate stale-live,
sealed/superseded, final, and supporting-read cases.

BUG-02 — Completion-review scope boundary is volatile. Turn completion already
persists Passed status, but rollout reconstruction discards it and resume,
rollback, and replacement-history compaction can review obsolete requirements.
Repair: reconstruct the newest surviving Passed boundary as an Option that can be
cleared and preserve/apply it on all history replacement routes. Validate resume,
rollback, and compaction histories.

BUG-03 — Evidence summaries label every historical command receipt as current
"Validation" despite epoch, failure, timeout, and possible-mutation metadata.
Repair: render explicit command evidence with epoch/currentness/outcome/mutation
semantics and reserve validation wording for current successful validation-class
receipts. Validate stale, failed, timed-out, mutating, and current receipts.

BUG-04 — Completion review drops InputImage/LocalImage requirements because its
request builder extracts only non-contextual InputText and launches a text-only
reviewer. Repair: preserve bounded requirement-associated image inputs and mark
the review partial if an applicable image cannot be conveyed. Validate mixed and
image-only requirements with distinct images.

BUG-05 — Unified-exec startup is cancellation-unsafe. A mutation lease is acquired
before launch, while process-store insertion, ledger attachment, watcher startup,
and initial-active state are split by cancellable awaits; pre-ledger cancellation
can leak the process and lease until stale cleanup. Repair with an RAII startup
owner/guard whose Drop rolls back the store, kills the process tree, clears active
state, and finalizes the lease unless registration is atomically committed.
Validate barriers before launch and after store insertion/before ledger commit.

BUG-06 — Goal rendering escapes XML before a 16,000-byte cap. A protocol-valid
4,000-character objective made of ampersands expands to 20,000 bytes, loses its
tail, and can split an entity. Repair with a 20,000-byte protocol-derived escaped
budget and atomic entity-safe legacy truncation. Validate all three renderers with
a max-valid ampersand-heavy objective ending in a sentinel.

BUG-07 — Windows rusty_v8 target fallback uses OSArchitecture. Under ARM64 Windows
running x64 PowerShell/Rust under emulation it selects an ARM64 archive while
Cargo builds for the x64 process/toolchain host. Repair by preferring explicit
Rust/Cargo target data and falling back to ProcessArchitecture. Validate cleared
processor environment variables with differing process/OS architectures.

BUG-08 — Installed continuity smoke cleanup is success-only. Failures after
creating the real capsule or sibling temp leave repository harness state behind.
Repair with outer finally cleanup of temp then capsule while preserving the
original exception. Validate failures before temp, before replace, after replace,
and during resumed validation.

BUG-09 — Async SDK cancellation detaches asyncio.to_thread but asyncio.run still
waits for that default-executor worker during shutdown. Repair unbounded calls
with the existing daemon-thread/concurrent-Future pattern. Validate that the
runner returns before a blocked worker is released.

BUG-10 — Bounded notification polling awaits and discards a queue-get result
during cancellation, losing an event and potentially hanging later waits. Repair
with thread-safe nonblocking queue polling plus cancellable sleep. Validate A/B
ordering across cancellation for global, login, turn, and goal queues.

BUG-11 — TypeScript iterator cleanup sends one SIGTERM and waits forever if the
child ignores it. Repair with processExited-based bounded SIGTERM grace, SIGKILL
escalation, and a final bounded wait. Validate ignored-SIGTERM and never-exits
fakes.

BUG-12 — Not every Cargo lane producer participates in prune coordination; direct
Unix recipes and the Windows package-test path can start after the pruner's final
idle check and before rename. Repair by routing all lane recipes through one
cross-platform reservation protocol and make policy tests require it. Validate a
barrier at prune's final check for each recipe family.

BUG-13 — Deferred trash cleanup accepts trash-named reparse/junction directories
and recursively deletes them. Repair by re-fetching and rejecting reparse points
immediately before every deletion/enumeration pass. Validate an external sentinel
behind a trash-named junction under Windows PowerShell 5.1 and pwsh.

BUG-14 — cargo-lane.ps1 rejects only '.' and '..', allowing pure-dot '...' lane
names that normalize unsafely on Windows. Repair by rejecting ^\\.+$ before path
creation. Validate '.', '..', and '...' leave lane state untouched.

BUG-15 — Stray-target cleanup checks .cargo-lock twice and then recursively
deletes without a producer reservation, leaving a check/delete race. Repair by
quarantining under a producer/pruner protocol or refusing automatic deletion for
uncoordinated producers. Validate a producer acquiring between classification
and deletion.

BUG-16 — POSIX coordination declares a 30-second deadline but uses blocking
flock(LOCK_EX), so a live holder can block forever. Repair with LOCK_NB plus the
existing deadline/retry loop. Validate a held lock reaches TimeoutError.

BUG-17 — Diagnostics call raw Remove-Item -Recurse -Force commands "safe prune
suggestions" even though they bypass every guarded prune check. Repair by pointing
only to the guarded target-prune route. Validate no direct recursive-delete
command is emitted.

BUG-18 — Cargo-lane tests prefer pwsh while production recipes use Windows
PowerShell 5.1, so host-specific defects can pass CI. Repair by preferring
powershell and adding a separate pwsh matrix where applicable.

BUG-19 — The npm artifact cache ignores authoritative remote artifact id/digest;
same-name/same-size artifacts can reuse stale local binaries. Repair by carrying
remote identity through selection/markers, downloading the exact id, and checking
the authoritative SHA-256 before extraction. Validate changed identity and digest
mismatch without replacing a valid cache.

BUG-20 — Attempt-qualified GitHub Actions URLs are accepted but the attempt number
is discarded; status and artifacts come from the latest attempt while the old URL
is displayed. Repair by retaining/honoring attempt_id end-to-end or rejecting such
URLs. Validate attempt 1 cannot inherit attempt 2 results.

BUG-21 — npm source/dirty validation happens after repo-local cache/vendor writes,
so the script can reject its own new files. Repair with a pre-write preflight and
a final check excluding only owned paths, or reject unsafe repo-local paths.
Validate owned cache writes and concurrently introduced unrelated dirt.

BUG-22 — Extracted npm archive cache identity uses only target/size/mtime and its
tree digest omits file mode. Equal-stat replacement and executable-bit changes can
reuse invalid output. Repair with archive content SHA-256 plus normalized file
mode in the tree digest. Validate equal-stat different bytes and mode removal.

BUG-23 — npm archive lock acquisition retries every OSError forever, including
permanent unsupported/invalid-lock errors. Repair by retrying recognized
contention only, propagating permanent failures, and bounding waits. Validate
contention-then-success and immediate permanent failure.

BUG-24 — workflow_preflight publishes the registry claim before --output; an
output-write failure reports failure but leaves a live one-hour claim. Repair by
restoring/removing the same-assignment registry receipt under lock if output
publication fails. Validate new-claim cleanup and prior-receipt restoration.

BUG-25 — workflow_preflight uses os.name to choose case folding, so case-only path
aliases can bypass ownership conflicts on case-insensitive POSIX filesystems.
Repair with a repository-filesystem comparison policy (or conservative normalized
case-folded claim keys). Validate platform-independent case-only overlap.

NONCODE-01 — Microsoft/Windows/PowerShell/ModuleAnalysisCache is an untracked,
non-UTF-8 generated PowerShell module-analysis cache with no repository consumer.
Remove only that exact file and verify it disappears from status; if it regenerates,
isolate the responsible test's local-app-data directory.
