They contain SQLite/WAL/SHM state, user thread/log text and local paths, installation IDs, raw validation-history keys, and possible credential-like strings whose validity was not tested. They are a privacy and publish blocker. The review will not delete 134 MB of untracked user evidence or silently ignore it without owner authorization; it must remain uncommitted and be moved, deleted, or redacted by an explicit owner decision.

HIGH GW-2: stable Git metadata can remain stale after a HEAD-only change because dependency capture and watcher-generation validation were removed/swapped. Restore full stable capture and generation checks.

HIGH HIST-1: cloned ContextManager branches share prepared-history cache entries keyed only by revision and policy, allowing one diverged branch to receive another branch's prepared prompt. Add branch identity without redesigning the cache.

HIGH VA-4: rejected steer input updates validation authorization before turn/task/empty-input checks. Move authorization mutation after all admission checks.

HIGH TEXEC-1: a validation leader drops its sole waiter before execution, cancelling its own leader token. Retain the waiter until completion.

HIGH/MEDIUM VA-1a: CR/LF-separated validation commands can be classified as non-validation and evade a user prohibition. Repair only safe line-boundary normalization; generalized shell parsing is deferred.

MEDIUM CT-1: absent response tools are measured as JSON null and charged one token despite wire omission. Measure None as zero.

MEDIUM GW-3/GW-4: project namespace uses the expensive/wrong dependency capture and hardcodes Windows NUL on non-Windows. Use specialized capture and DISABLED_HOOKS_PATH.

MEDIUM VA-3: bare cargo test test_name is classified as package-wide. Recognize the immediate positional selector; generalized ecosystem flag parsing is deferred.

MEDIUM TEXEC-2: a launch-time skipped validation succeeds for the leader but is published as failure to followers because success is derived only from exit code. Preserve explicit skipped success.

MEDIUM TEXEC-3: an explicit root beneath target/vendor/node_modules bypasses generated/vendor defaults because policy is evaluated relative to that root. Evaluate policy repository-relative.

MEDIUM TEXEC-4/TEXEC-5: task-locator rendered instruction reads and routing-manifest reads can influence returned results without complete final snapshot verification/supporting-read provenance. Admit, hash, and reverify those contributors.

MEDIUM STATE-1: validation-history lookup can publish a stale cache value after a concurrent record evicts the key. Add per-key generation/serialization and a deterministic race test.

MEDIUM PUBLISH-1: both final local-publish recipes pass -SkipPreflightCheck and their test enforces it, disabling the script's default release cargo-check guard. Remove the flags and invert the test.

LOW ARTIFACT-1: root a and b are disposable 82-byte temp-test path files with no consumers. Delete them after this ledger gate.
