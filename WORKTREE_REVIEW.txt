F005 CONFIRMED - codex-rs/app-server/src/command_exec.rs test windows_sandbox_streaming_exec_is_rejected contradicts the changed implementation, which now supports stdout/stderr streaming for Windows-sandbox execution. Disposition: convert the test into an acceptance/start-path assertion with the supported default cap.

F006 CONFIRMED - deterministic focused-validation failure classification is lost whenever unified exec stores a live process before its initial wait. exec_command only records DeterministicFailureRecord when finish_running_process says the process was not tracked; the exit watcher and tracked-process finalizer currently record a generic exit. This defeats exact-repeat suppression for normally yielded or background validation commands. Disposition: carry the trusted deterministic contract and start time in running-command bookkeeping, record it exactly once at every tracked terminal path, refresh its evidence after artifact finalization, and add focused tests.
