Definitions:

- First edit: model call that emitted the first successful patch, immediately before `patch_apply_end(status=completed)`.
- Tool runtime: union of outer tool-call-to-result intervals; parallel nested tools are not double-counted.
- Orchestration gap: request-to-edit wall time minus tool runtime.
- Logical generation: top-level `response_item(type=reasoning)`.
- Correct-owner time: earliest correct owner/path evidence, even if the model later abandoned it.
- Sufficient-evidence time: judgment-coded point where the eventual first edit was supported by owner, mechanism, and compatibility evidence.
- “Material”: a deliberately generous test—first locator/Atlas/image result, a substantially novel source span or search, a novel reproduction, or the first useful Git observation. This therefore overestimates useful work.
