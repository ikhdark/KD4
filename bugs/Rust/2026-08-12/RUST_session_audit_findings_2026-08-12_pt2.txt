- 5,534 evidence-producing tool calls, approximately 264 per task.

## Recommended operating shape

For a typical directed KD4 fix, sufficient investigation should normally be:

1. If no owner is supplied, one `locate_task`.
2. One batched read of applicable instructions and the owner span.
3. One batched read of known callers, tests, contracts, and validation route.
4. One Git snapshot/diff.
5. Further search only for a named unresolved question or incomplete/capped evidence.

That is generally **3–6 model/tool boundaries**, not the observed **95.4/task**. Complex cross-cutting work can exceed that, but it should do so because the closure expanded—not because the same owner, instructions, spans, or search questions were rediscovered.
