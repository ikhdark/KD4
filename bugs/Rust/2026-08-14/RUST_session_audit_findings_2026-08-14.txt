Each receipt has an exact content hash and artifact ID ([source_closure.rs](C:/Users/kuh/Desktop/kd4/codex-rs/core/src/tools/handlers/source_closure.rs:95)), and replay verifies artifact hash and re-reads metadata ([source.rs](C:/Users/kuh/Desktop/kd4/codex-rs/core/src/tools/handlers/source.rs:3443)), but `permits_reuse` rejects it after any mutation revision change.

2. Medium-high: exact per-path Git freshness is mixed with repository-wide mutation counters

Git-observation freshness hashes each observed path’s size, timestamps, watcher state, and stable file identity, but also hashes the global mutation and host-mutation generations ([source.rs](C:/Users/kuh/Desktop/kd4/codex-rs/core/src/tools/handlers/source.rs:3384)). Any unrelated mutation therefore reopens the source closure and reruns `git rev-parse`, `git status`, and `git diff` ([source.rs](C:/Users/kuh/Desktop/kd4/codex-rs/core/src/tools/handlers/source.rs:3336)).

The mutation tracker already knows exact changed paths. A scoped mutation identity, plus watched `.git/HEAD` and index identities where needed, would preserve correctness without invalidating unrelated path observations.
