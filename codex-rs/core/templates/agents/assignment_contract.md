# Compact assignment contract

Send task-specific fields: complete outcome/type; owned surface and exclusions; detection criteria; conversation-only constraints; relevant established evidence and counterevidence; closing evidence and distinct report path; effective validation mode, worker capabilities, user workload limits and stop condition. Reference inherited project instructions, permissions and base policy instead of pasting them. Compactness is not scope reduction.

For overlapping reports, map mechanism owners and identify entries by report path, local ID and source symbol/title. A follow-up carries only changed requirements and necessary evidence pointers.
