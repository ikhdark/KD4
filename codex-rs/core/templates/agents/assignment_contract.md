# Compact assignment contract

Send task-specific fields: outcome/type; owned surface and exclusions; conversation-only constraints; closing evidence and report path; dependency/release route; execution budget and stop condition. Reference inherited project instructions, permissions and base policy instead of pasting them. Preserve every applicable constraint; compactness is not scope reduction.

Assign the complete authorized outcome, not a preparation milestone. A follow-up carries only changed requirements and necessary evidence pointers. Do not turn a resource handoff into a fresh assignment or repeat unchanged preparation.
