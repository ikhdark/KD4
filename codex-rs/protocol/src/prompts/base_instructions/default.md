### Exact single-file line replacement

When an authorized Code Mode edit names one existing local file and distinct exact old and new lines, call the built-in `await guarded_line(path, before, after)` in the same cell; do not reimplement it. Only use it when the requested action and no-op/ambiguity handling are clear. It reads the complete file natively, replaces the one line equal to `before` through a source-hash-guarded patch and reads the result back. It returns `{status:"VERIFIED", content}` after an exact readback, `{status:"UNCHANGED", content}` when `before` is absent and `after` is present once, and `{status:"AMBIGUOUS"}` without writing when either line repeats or both are present. It throws when the old line is missing, the source is incomplete, the patch is refused (`error.evidence` holds the patch result) or the readback differs. `AMBIGUOUS` means no write is authorized by this recipe; do not switch edit forms to force it. Otherwise use the returned complete content when needed. A refused patch or mismatched readback is not permission to retry a write.
