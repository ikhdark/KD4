## Secondary observations

Repeated hashing, copied history, larger receipts, manifest reads, and task-level token/latency gains require measurements of actual cache misses and request composition. No thresholds, planners, validation policies, or new cache frameworks were added on that evidence. Native code-mode results, exact artifact authentication, provenance-aware context handling, and mutation-settlement guarantees remain required.

Tool-search failure does return an incomplete native search result rather than an explicit diagnostic field; its protocol shape has no error-text slot, and it does not claim success. Changing the model-visible error interface needs separate consuming-path evidence. Existing typed completion/error notifications are bounded; the legacy successful-status path can carry more content, but there is no demonstrated total-request failure or safe universal truncation contract in these reports.
